AGENT TASK ENGINE · 五模块 × 四道 STOP 门

复杂交付，一张验收单。

AutoFlow 跑在你的 Agent 里，把 Word 文档、真实截图、图表、视频和提交包编排成可验证的工作流：每个产物落盘可查，关键节点停下来等你确认，交付像验收单一样签收。

到 GitHub 安装 先看交付凭证 ↓
git clone https://github.com/qiuy-collab/AutoFlow.skill.git

模块台账

五个模块覆盖一次交付的全部产物。单模块、无依赖的小交付走 direct 直出；多产物交付走 managed，任务编成 DAG，状态落盘、中断可续跑。

编号 模块 交付物 核对要点
M-01 task GitHub-first 检索、项目构建与可运行性证据 构建可复跑，证据落盘
M-02 image 真实浏览器捕获、AI 生成电脑截图、确定性图与基于真实数据的图表 每图带来源标注
M-03 office Word、PPT、Excel 的创建、填充、渲染审查与计划级校验 officecli 逐页校验
M-04 video 既有视频分析、录制、生成与处理 帧级核对后入库
M-05 package 组装干净的 submit/ 交付目录与可验证清单 杂物清零，逐项打勾

内置四个插件按任务选用：officecli 结构化校验与渲染 · minimax-docx 复杂 Word 后端 · nature-figure 出版级图表 · impeccable 前端设计质量。

四道 STOP 门

不夸大自动化。关键节点 Agent 停下来，把方案和产物摆上台面，由你确认后才继续——这是与黑盒自动化的根本区别。

  1. 1

    PLAN开工前 · 计划确认

    Agent 给出执行模式、任务拆解与目录结构，你点头才动手。

  2. 2

    SOURCE素材来源 · 入单确认

    截图、生图、图表与文档素材的来源逐项登记，AI 生成一律照实标注。

  3. 3

    VISUAL视觉产物 · 逐张过目

    图像与文档渲染页逐张过目，不合格当场重做，合格才算过门。

  4. 4

    DELIVERY交付签收 · 清单核对

    submit/ 目录与可验证清单逐项核对，全部通过才交付，像验收单一样签收。

交付凭证

以下全部出自同一个演示项目——「校园活动报名管理系统」（Spring Boot + MySQL）。真实截图与 AI 生成示意图分别标注，来源可查。

开始使用

把下面任一段交给你的 Agent（Claude Code、Codex 等均可），装完跑 env-check 确认可用。

STEP 1 · 复制这段话发给 Agent
从 https://github.com/qiuy-collab/AutoFlow.skill 克隆仓库，把完整的 autoflow Skill 目录安装到本地所有 Agent 的 skills 库中（如 ~/.claude/skills/、~/.codex/skills/ 等）。 安装后阅读 references/init.md 初始化环境，然后运行 env-check 确认可用。
STEP 2 · 或自己克隆仓库
git clone https://github.com/qiuy-collab/AutoFlow.skill.git

任务规模决定模式：单模块、无依赖的小交付走 direct；涉及来源选择、多产物依赖、文档或打包的交付走 managed（带全部 STOP 门）。
